# tut-code-meter

PC版Chrome向け拡張機能のコンセプトです。
公開名とリポジトリ名はともに`tut-code-meter`です。

## 背景と意図

普段ブラウザで読んでいる文章を、漢直のTUT-Codeを練習する教材にします。記事を開いたとき、最初に知りたいのは「この文章の漢字は、今の自分でもどれだけ打てるか」です。未習得字を見つけたら、その字が本文中で使われている単語を、よく出る順に練習材料として取り出します。

「カバー率メーター」は、現在のカバー率と全習得時のカバー率を併記する機能名の候補です。

ストアの説明文案は「読んでいる文章の漢字をTUT-Codeでどれだけ打てるか表示します。未習得字を含む単語を、よく出る順にコピーして練習できます。」です。

## 要件一覧

### 入力と集計範囲

| 項目 | 仕様 |
|---|---|
| 入力 | TUT-Codeで直接入力できる2525字の集合と、そのうち本人が習得済みの文字の集合を使用します。「打てる」は習得済みリストへの登録で判定します。 |
| 通常の閲覧 | 今の画面に見えている本文を集計します。スクロールが止まったら、その時点の表示範囲に更新します。集計開始ボタンを押す操作は不要です。 |
| 範囲選択 | 本文に選択範囲がある間は、その範囲を優先します。選択を解除すると画面内の本文に戻します。統計と単語一覧は同じ範囲を参照します。 |
| 数え方 | 漢字の延べ出現数を数えます。同じ漢字が5回出れば5字分です。かな・英数字・句読点はカバー率の分母から除きます。 |

### カバー率

範囲内の漢字を「習得済み」「TUT-Code内で未習得」「TUT-Code外字」の3種類に分類します。「外字」は入力として与えた2525字の集合に含まれない漢字を指します。

| 指標 | 分子 | 分母 | 用途 |
|---|---|---|---|
| 現在のカバー率Q | 習得済みの漢字の延べ出現数 | 外字を含む全漢字の延べ出現数 | この文章で今打てる割合を示します。 |
| 全習得時のカバー率P | 習得済みと未習得を合わせたTUT-Code対象漢字の延べ出現数 | Qと同じ | 2525字をすべて習得したとき、この文章で打てる割合を示します。外字を含む文章では100%未満になります。 |
| TUT-Code対象内の習得率 | 習得済みの漢字の延べ出現数 | TUT-Code対象漢字の延べ出現数 | この範囲に出た対象字の習得度を示します。すべて打てれば100%です。 |

QとPは「現在」「全習得時」の順に、割合と字数を併記します。両者の差は、この範囲の未習得字を覚えることで増やせる割合です。

> 現在75%(15/20字) ｜ 全習得時90%(18/20字)  
> TUT-Code対象内の習得率 83.3%(15/18字)

### 練習候補とコピー

- 単語ごとに「本文での表記」「その中の打てない字」「範囲内の出現回数」を表示します。打てない字を含む語を1語1件にまとめ、出現回数の多い順に並べます。
- 文字単位でも出現回数を把握できるようにします。「構築」が2回、「構成」が1回なら、未習得字「構」を覚えると、この範囲で新たに3箇所を打てます。文字の回数は、単語の切り方に依存しないよう本文から数えます。
- 外字を含む語には「外字あり」と表示します。初期設定ではその語をコピー対象から外し、直接入力で最後まで打てる語を練習材料にします。
- 「単語をコピー」を1回押すと、単語だけを出現回数順に、1行1語のプレーンテキストとしてクリップボードへ書き込みます。練習先はブラウザ版の[eelll/JS](https://miau.github.io/eljs/)を想定しています。

### 表示と会議時の休止

| 表示場所 | 通常時の動作 |
|---|---|
| Chromeのツールバー | 固定した拡張アイコンにQを表示します。アイコンにポインターを合わせるとQとPを併記し、クリックせずに確認できるようにします。 |
| 右サイドパネル | 上部にQとP、その下に対象内の習得率と3分類の字数を置きます。続けて練習候補とコピーボタンを表示します。一度開けば、タブを切り替えてもその場で確認できます。 |
| 本文 | 装飾を使う場合の案は、習得済みを通常表示、未習得を色付き、外字を灰色の点線の下線とします。未習得字の配色候補は淡い黄色の背景または文字色の変更です。 |

職場では、同じChromeプロファイルのいずれかのウィンドウでMeetの会議URLを開いている間、プロファイル全体の学習表示を休止します。既に付けた本文の装飾を取り除き、アイコンの割合、ツールチップの統計、開いているパネルの学習情報を隠します。会議中に別の資料を開いても休止を維持します。

## 実現方針一覧

| 処理 | 方針 |
|---|---|
| 対象テキストの取得 | 選択があれば選択文字列を使い、通常時は画面内の本文を使います。記事全体や拡張の表示を誤って数えないようにします。 |
| 集計 | 2つの文字集合への所属から漢字を3分類します。同じ集計結果からQ・P・対象内の習得率を計算し、アイコンとパネルで値を一致させます。 |
| 単語の抽出 | `Intl.Segmenter("ja", { granularity: "word" })`を使います。「環境を構築する」と「構築手順」から「構築」を数えられ、「取り込む」のような送り仮名を含む語も元の表記で扱えます。漢字を連続部分だけで切ると「構築手順」を1件として数えてしまいます。[MDNのIntl.Segmenter](https://developer.mozilla.org/ja/docs/Web/JavaScript/Reference/Global_Objects/Intl/Segmenter) |
| Chromeの表示 | `chrome.action`でバッジとツールチップを、`chrome.sidePanel`で詳細表示を実装します。本文に重ねる常時ポップアップは使わず、記事の閲覧中はアイコンを見るだけでQを確認できます。[Action API](https://developer.chrome.com/docs/extensions/reference/api/action)・[Side Panel API](https://developer.chrome.com/docs/extensions/reference/api/sidePanel) |
| Meetの検出 | Meetに対するホスト権限`https://meet.google.com/*`を使い、`chrome.tabs.query({ url: "https://meet.google.com/*" })`の結果を確認します。現在のウィンドウに絞らず、各URLのパスが標準的な会議コード形式(例 `/abc-defg-hij`)に合うかを判定します。クエリ文字列は判定に影響しません。[Chrome Tabs API](https://developer.chrome.com/docs/extensions/reference/api/tabs) |
| 休止の同期 | 拡張起動時とタブの作成・URL変更・削除・置き換え時に再判定します。会議URLが1件以上なら全対象タブで休止し、最後の1件がなくなれば再開します。同じプロファイルからインストールしたPC版Meetアプリ(PWA)の独立ウィンドウも検出対象です。[Google MeetのPC版PWA](https://support.google.com/meet/answer/10708569?hl=ja)・[Chromiumのタブ検索実装](https://chromium.googlesource.com/chromium/src/+/2647139922107a62ff85b1d3eb3d2e9d88e51eb1/chrome/browser/extensions/api/tabs/tabs_api.cc) |

休止のきっかけは会議URLの存在です。Meetのホーム画面だけなら通常表示し、会議の参加前画面で休止します。退出後も会議URLが残れば休止を続けます。この方式なら、利用者が資料を共有する直前に手動で非表示にする操作を省けます。

Meetのタブ共有では、対象ページに描画した色や点線も共有されます。Chromeのウィンドウ共有ではツールバーとサイドパネルも、画面全体の共有ではそのディスプレイに表示した情報も映り得るため、休止対象には3箇所とも含めます。[Google Meetの画面共有](https://support.google.com/meet/answer/9308856?hl=ja)

## ユースケース

### 記事を読む

記事を開くと、集計操作なしでアイコンに現在のカバー率が出ます。ある段落だけを選ぶと、割合と練習候補の両方がその段落の値に変わります。選択を解除すると、どちらも画面内の本文の値に戻ります。

### 数値と練習語を検算する

実装の受け入れ例として、以下の4語が「、」で区切られて指定回数だけ出る本文を使います。この例の入力集合では未習得字を「構」、外字を「彙」とし、それ以外の登場漢字は習得済みとします。

| 語 | 出現回数 | 集計結果 |
|---|---:|---|
| 設計 | 5 | すべて習得済みです。カバー率に反映します。 |
| 構築 | 2 | 未習得字「構」を含みます。コピーする1語目です。 |
| 構成 | 1 | 未習得字「構」を含みます。コピーする2語目です。 |
| 語彙 | 2 | 「外字あり」と表示します。初期設定のコピー対象から外します。 |

漢字は延べ20字で、習得済み15字、未習得3字、外字2字です。Qは75%、Pは90%、対象内の習得率は83.3%です。「構」を習得済みに変更して同じ範囲を再集計すると、Qは90%、Pは90%、対象内の習得率は100%になります。

「構」を覚える前に「単語をコピー」を押すと、内容は次の2行です。

```text
構築
構成
```

### 職場で画面を共有する

1. 資料タブで本文の装飾とサイドパネルを表示し、別ウィンドウでMeetの会議リンクを開きます。参加前の時点で資料の装飾と拡張の学習情報が消えることを確認します。
2. 会議ウィンドウを背面に移し、別の資料を開きます。新しい資料も休止状態になることを確認します。
3. 会議URLを2件開いてから1件を閉じます。残りの1件を閉じるか会議以外のURLへ移動するまで、休止が続くことを確認します。
4. 同じChromeプロファイルのMeetアプリ(PWA)でも同じ操作を行います。実際の会議では、タブ・ウィンドウ・画面全体の各共有方法について、受信側で学習情報が映らないことを確認します。

## 補足と今後の検討事項

1. 2525字の実データ、習得済みリストの初期値・登録・更新方法は未確定です。この文書の受け入れ例は検算用に文字の所属を指定しています。
2. 初版で決めたエクスポートの範囲はクリップボードまでです。公開版eelll/JSで独自教材を取り込む手順、複数記事をまたいだ収集結果の保存、選択した複合語をそのまま手動追加する案は未確定です。
3. 本文装飾の初期設定と具体的な配色、分母が0件の指標の表示、同じ出現回数の語の並び順は未確定です。
4. Meetによる休止は、同じChromeプロファイルで標準形式の会議URLを開く場合が対象です。別プロファイルや別ブラウザでの会議は検出対象外です。PWA対応はChromiumの実装に基づく方針で、職場端末とMeet受信側での動作は実装後の確認事項です。
