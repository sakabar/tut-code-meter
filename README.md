# tut-code-meter

PC版Chromeで読んでいる文章の漢字を、TUT-Codeでどれだけ打てるか表示するTampermonkey用スクリプトです。未習得字を含む単語を出現回数順にコピーして練習できます。

## インストール

1. PC版ChromeにTampermonkey 5.3以降をインストールします。Chromeの拡張機能の詳細で「ユーザー スクリプトを許可する」をオンにします。[Tampermonkeyの設定手順](https://www.tampermonkey.net/faq.php?locale=en&q=Q209)
2. [tut-code-meter.user.js](./tut-code-meter.user.js) の内容をすべてコピーします。Tampermonkeyの「新規スクリプトを追加」で初期内容を置き換え、保存します。ビルドは不要です。
3. 集計したい記事と、すでに開いているMeetのタブを再読み込みします。ChromeのTampermonkeyのサイトアクセス設定で、記事のサイトと `https://meet.google.com` での実行を許可してください。

## 使い方

- 記事の右下に「現在 0%」などのメーターが出ます。初回は習得済み字が空です。メーターを押して「設定」を開き、打てる漢字を貼り付けて「習得済み字を保存」を押します。空白・改行・重複を除いて登録し、対象外の文字は保存結果に表示します。あとからこの欄で削除もできます。
- 打てなくなった漢字は、設定の「忘れた字」欄に貼り付けて「忘れた字に移す」を押します。たとえば「構築」と入力して「構」だけが習得済みなら、「構」を移し、「築」は対象にならなかったことを表示します。習得済み欄から直接消した字は、従来どおり通常の未習得に戻ります。
- 設定の「忘れた字の一覧」には、現在の記事に出てこない字も含めて全件表示します。覚え直したら「習得済みに戻す」を押すか、習得済み欄にまとめて登録できます。「打てない字と出現回数」では、集計範囲に出た忘れた字をグループで確認できます。忘れた字はカバー率では未習得に含まれ、その字を含む語が練習候補に戻ります。
- 普段は読み込み済みの本文を「ページ全体」として集計します。スクロールしてもカバー率・字数・コピーする単語の順位は変わりません。段落を選択すると「選択範囲」の結果に切り替わり、選択を解除すると全文の結果に戻ります。
- 無限スクロールなどで新しい段落が読み込まれると、ページ内にある本文で集計を更新します。サイトが古い段落をページから取り除く場合は、その段落も集計から外れます。
- メーターにポインターを合わせると「現在」と「全習得時」の割合が分かります。クリックして開くと字数と「対象内の習得率」も確認できます。いずれも漢字の延べ出現数を使い、分母が0字の指標は `—` と表示します。

| 指標 | 計算式 |
| --- | --- |
| 現在 | 習得済み字の出現数 ÷ 全漢字の出現数 |
| 全習得時 | TUT-Code対象字の出現数 ÷ 全漢字の出現数 |
| 対象内の習得率 | 習得済み字の出現数 ÷ TUT-Code対象字の出現数 |

- 「単語をコピー」で、表記を重複させずに1行1語でコピーします。頻度が同じ語は本文で先に出る順です。「外字あり」の語は、チェックを入れるとコピーに含められます。練習先として [eelll/JS](https://miau.github.io/eljs/) を想定しています。
- 「打てない字と出現回数」から1字ずつ習得済みにできます。「設定」で本文装飾をオンにすると、集計範囲のうち画面内にある未習得字に淡い黄色、外字に灰色の点線が付きます。
- 対象はHTTP・HTTPSページのトップ文書です。記事やメイン領域を優先し、見つからなければ本文全体からナビゲーションや入力欄などを除いて集計します。記事本文とコピー候補はページ内で処理します。習得済み字と表示設定はTampermonkeyに保存し、同じプロファイルのタブに反映します。

## Meetでの画面共有

同じプロファイルで標準の会議URL（例 `https://meet.google.com/abc-defg-hij`）を開くと、参加前から全対象タブのメーターと本文装飾を隠します。最後の会議タブを閉じるか通常ページへ移動すると再開します。退出後も会議URLが残っている間は休止します。

スクリプトが実行されたタブの状態をTampermonkey経由で照合します。タブを閉じたあとの再開は次の照合時です。Chromeがバックグラウンドの実行を制限している間は反映が遅れる場合があります。別プロファイルの会議や、サイト権限で実行を禁止したMeetは検出できません。会議タブからChromeの設定画面などスクリプトが動作しないページへ直接移動すると、休止が続く場合があります。そのタブを閉じるか、スクリプトが動作する通常ページへ移動すると再開します。

職場端末での確認手順です。

1. 資料のパネルと本文装飾を開き、別ウィンドウでMeetの会議リンクを開きます。参加前に学習表示が消え、別の資料を新しく開いても表示されないことを確認します。
2. 会議URLを2件開き、片方を閉じます。残りの1件を閉じるかMeetホームへ移動すると表示が戻ることを確認します。
3. 同じChromeプロファイルにインストールしたMeetアプリ（PWA）でも同じ操作を試します。タブ・ウィンドウ・画面全体の各共有方法で、受信側にメーターや本文装飾が映らないことを確認します。

## 開発とライセンス

Node.js 22以降で `node --test test/meter.test.cjs` を実行すると、構想文書の20字の例、コピー順、対象字、入力処理、会議URLの判定を検証できます。

Chromeでローカルの [test/page-scope.html](./test/page-scope.html) を開くと、全文集計・スクロール時の装飾・範囲選択・本文追記・忘れた字の登録と再習得を検証できます。成功するとページに「PASS」と表示されます。
