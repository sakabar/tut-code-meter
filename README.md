# tut-code-meter

読んだ記事の漢字をTUT-Codeでどれだけ打てたか、あとから振り返るためのTampermonkeyスクリプトです。記録対象の記事では、本文の打てない字をハイライトできます。履歴はTampermonkeyメニューから開きます。

## インストールと記録の開始

1. PC版ChromeにTampermonkey 5.3以降をインストールし、拡張機能の詳細で「ユーザー スクリプトを許可する」をオンにします。[Tampermonkeyの設定手順](https://www.tampermonkey.net/faq.php?locale=en&q=Q209)
2. [配布用スクリプト](./tut-code-meter.user.js)の内容をTampermonkeyの「新規スクリプトを追加」に貼り付けて保存します。以前の版がある場合はそのスクリプトを更新してください。習得済み字・忘れた字は引き継がれます。
3. 記事と、すでに開いているMeetのタブを再読み込みします。Tampermonkeyに、対象サイトと `meet.google.com` へのアクセスを許可してください。
4. **初期状態は記録オフです。** 記事のタブでTampermonkeyメニューから「学習設定を開く」を選びます。保存項目を確認し、「許可したサイトだけ記録」か「除外したサイト以外を記録」を選び、ホスト名を入力して「記録設定を保存」を押します。ホスト名は完全一致です。たとえば `example.com` と `news.example.com` は別々に指定します。除外リストを空にすると全サイトが対象になります。

## 保存される内容

対象の記事にフォーカスが当たった時点を閲覧日時として、読み込み済みの本文全体を集計します。バックグラウンドで開いたタブは、初めて手前に出したときに対象になります。すぐ別のタブに切り替えても、元の記事が開いたままなら、遅れて本文が届いた時点で、フォーカス時の習得状態を使って記録します。漢字がないページは履歴に残りません。スクロール位置やテキスト選択は集計結果に影響しません。記事・メイン領域を優先し、ナビゲーション、非表示部分、入力欄などは除きます。

- 閲覧日時（端末の現地日時）、ページタイトル、サイト名、URL（クエリ・フラグメントを含む）を保存します。
- 3つの指標に、割合と分子・分母の延べ字数を保存します。分母が0のときは `—` と表示します。

| 指標 | 計算式 |
| --- | --- |
| 現在のカバー率 | 習得済み字 ÷ 全漢字 |
| 全習得時のカバー率 | TUT-Code対象字 ÷ 全漢字 |
| 対象内の習得率 | 習得済み字 ÷ TUT-Code対象字 |

- 打てなかった字を含む語（未知語）について、本文中の表記、出現回数、打てなかった字、そのうち閲覧時に「忘れた字」だったものを保存します。標準のTUT-Code配列で打てない漢字（外字）を含む語も記録します。
- 同じURLは現地日付ごとに1件です。同日中に読み直すと最新の結果に更新します。習得状態の編集だけで過去の記録が変わることはありません。

履歴はTampermonkeyのスクリプト保存領域に、自分で削除するまで残ります。記事本文の全文保存やスクリプトからの外部送信は行いません。

## 履歴の確認・コピー・削除

Tampermonkeyメニューの **「学習履歴を開く」** を選ぶと、その日の記録が表示されます。開始日・終了日は開くたびに端末の現地日付の今日に戻ります。両端の日付を含み、空欄にした側は期間を制限しません。

画面上部に期間集計、その下に新しい順で記事が並びます。期間集計の3指標は、各記事の分子・分母の延べ字数をそれぞれ合算してから割ったミクロ平均です。期間と記事のどちらの未知語一覧にも、TUT-Codeだけで打てる語を出現回数の多い順に表示します。期間集計では同じ表記の回数を合算します。

「記事別の記録」で記事を開くと、最初にコピー・削除ボタンが並びます。その下の「習得していない漢字」を開くと、1字ずつ登録できます。最後に、閲覧日時・URL・3指標と未知語の明細が表示されます。

| ボタン | コピーする内容（プレーンテキスト） |
| --- | --- |
| この期間の記録をコピー | 選択期間、記事件数、3指標のミクロ平均と字数、未知語と出現回数 |
| この記事の記録をコピー | 閲覧日時、タイトル、サイト名、URL、閲覧時の3指標と字数、未知語の明細 |
| 当時の未知語をコピー | 閲覧時に打てなかった語。あとで習得した語も含みます。 |
| 今も未知の語をコピー | 閲覧時の未知語のうち、今も打てない漢字が1字以上ある語。 |

どちらも期間全体と記事ごとに使えます。出現回数の多い順に、回数を付けず1行1語でコピーします。通常はTUT-Code対象字だけで打てる語を出力し、「(外字含む)」付きのボタンでは外字を含む語も出力します。該当する語がないボタンは無効になります。

「今も未知の語」は語全体で判定します。たとえば「構築」を読んだときに「構」が打てず、あとで「構」を覚えた場合、今「築」も打てれば「構築」は候補から外れます。「築」を忘れていれば候補に残ります。画面の明細と「記録をコピー」には閲覧時の内容が残ります。

期間集計または各記事で **「習得していない漢字」** を開くと、その範囲で出現回数の多い字から練習できます。候補は、閲覧時に未習得だったTUT-Code対象字のうち、今も未習得の字です。「忘れた字」も含みます。各行の **「習得済みにする」** を押すと、その字が期間と記事の両方の候補から消え、同じ位置で次の字を続けて登録できます。閲覧時の指標と未知語の明細は履歴に残ります。字ごとの回数を保存していない旧版の履歴では、保存済みの未知語から出現回数を数えます。

削除は記事1件、同じホストの全期間、全件から選んで確認します。削除時に開いていた記事は、そのタブを再読み込みしても記録が復活しません。改めて記事に移動したときは、新しい閲覧として記録します。

## 本文のハイライト

「学習設定を開く」の「本文の未習得字と外字をハイライト」で切り替えます。旧版の設定を引き継ぎ、未設定ならオンです。記録対象の記事で、画面内の未習得字・忘れた字に淡い黄色の背景、外字に灰色の点線を付けます。記事が表示されていれば、アドレスバーや別ウィンドウを操作中もハイライトが続きます。非表示のタブは再表示したときに装飾を更新します。本文を選択すると選択範囲だけを装飾し、選択を解除すると画面内の本文に戻ります。

## 習得済み字・忘れた字

Tampermonkeyメニューの **「学習設定を開く」** を選び、「習得済みの漢字」に打てる字を貼り付けて「習得済み字を保存」を押します。見出しには保存済みの字数が表示されます。たとえば標準2,525字のうち123字を登録すると、**「習得済みの漢字 (123文字/2525文字)」** と表示されます。

以前は打てた字を忘れたら、「忘れた字」欄に入力して「忘れた字に移す」を押します。その字は習得済みの字数から引かれ、「忘れた字の一覧」に移ります。思い出したら「習得済みに戻す」で1字ずつ戻せます。習得済みの欄から直接消して保存した字は、通常の未習得字になります。

## シークレット・Meet

シークレットウィンドウでの閲覧は記録しません。同じプロファイルで標準のMeet会議URL（例 `https://meet.google.com/abc-defg-hij`）を開いている間は、参加前から全タブで記録、ハイライト、履歴・設定画面の表示を休止します。最後の会議タブを閉じるか通常ページに移動すると再開します。別プロファイルやサイトアクセスが無効なMeetは検知できません。会議タブでスクリプトが動かないページへ移動した場合は、そのタブを閉じると休止を解除できます。
